Главная

GAIA Pipeline

Инфраструктура для воспроизводимых экспериментов с поведением LLM в benchmark loop: OpenAI-compatible proxy для test-time техник, launcher для GAIA / InspectAI и результаты запусков на разнородном compute.

Начать с общей цели Раздел результатов 
# practical pipeline
GAIA Benchmark
  -> InspectAI GAIA runner
  -> Test-Time Scaling Proxy
  -> OpenAI-compatible model backend
  -> Local / Colab / Mac / GPU inference
