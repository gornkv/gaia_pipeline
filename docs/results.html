Сравнение техник

Этот раздел нужен для baseline vs intervention: Best-of-N, self-consistency, context compaction, structured notes, budget-aware reasoning и других техник, которые подключаются через proxy hooks.

  • Score delta относительно baseline.
  • Дополнительные model calls и token budget.
  • Изменение количества tool calls.
  • Latency и стабильность запуска.
  • Качественные наблюдения по ошибкам и regressions.
